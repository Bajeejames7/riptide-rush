# Round 4 verification

Career now has five named tiers, six ordinary events and a named rival showdown per tier (35 events, 105 possible stars). All six event types run through renderer-independent rules in `src/core/career.js`. Ordered sectors supply Checkpoint Rush extensions; pickup events supply Boost Hunt counts; timed elimination freezes and hides knocked-out boats and excludes them from collisions. Checkpoint Rush has a stated harbour closing time so a fast boat cannot keep the event running indefinitely.

The map displays objectives, event type icons, direction, track, weather, stars and locks. The garage saves a selected hull/paint and three upgrade levels per stat per boat. Stars gate events, tiers, hulls and courses; reputation gates paints and upgrade access. Rival wins grant their hulls, and the final rival grants champion paint and full upgrade access. Three slots use `rr.career.v1`; settings retain the selected slot. Reset has a dedicated confirmation page. Non-career selectors restrict hulls/courses to unlocked content, with a persistent party-play override. Existing keyboard/controller menu navigation handles the new screens and now skips disabled selector options.

Career style scoring includes air time, drifting, boost chains, near misses, overtakes and clean laps. Popups appear in the race HUD; results show stars, objectives and total earned reputation. Boat contacts now invalidate clean laps. Later rivals have upgrades and no rubber band adjustment. Reverse routes rebuild sample order, headings, checkpoint progress, start grids, AI paths, ramps and scenery from the same directed samples.

Visual changes: soft white additive spray/splashes; broad warm sand beaches and dunes; harbour props and timber spans in place of castle-like towers/stone arches; six individually proportioned hulls with batched racing hardware, two-tone numbered original liveries, clearcoat and boost exhaust; rotated/coarser/weaker water detail normals and stronger white V wakes. Sunset/fog/rain variants use exposure, key light and fog changes. `startRace` clears the loading UI's DOM contents in every mode, including verify mode. `Graphics.autoTune` logic is unchanged.

Validation:

- `npm test`: 20 passing tests, zero failures. Added real AI/physics completion tests for all six event types, ordered two-lap reverse races on all tracks, timed elimination/frozen boats, progression/unlocks/upgrades and three-slot save round trips. UI/race bridge tests cover rival launch state, reward persistence, duplicate finish prevention and loading DOM removal. Updated boat-builder regression checks to assert source ownership, clearcoat, batched hardware and bounded submissions.
- `npm run build`: production Vite build, without Electron download or packaging.
- `npm run assets:audit`: actual imported and batched boat geometry is included, with maximum 437 triangles and four draws per boat. Conservative whole-course Low allowances: Sunspill 172,116 triangles / 109 draws; Aurora 113,008 / 99; Voltage 160,588 / 114. Each fits the existing 250,000-triangle / 150-draw Low budget. Shipped assets remain 13.42 MiB.

Structural geometry/draw allowances are not GPU timings. No Electron download, electron-builder execution or commit was performed.
